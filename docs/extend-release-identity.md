# 시간 연장 응답의 실행 버전

설정을 복제한 배포 버전의 인스턴스를 연장하면 스케줄러는 시간을 늘렸지만 백엔드는 실행 버전 누락으로 503을 반환했다
연장 응답에도 저장된 release_id와 registry_revision을 전달해 백엔드가 처음 선택한 실행 버전을 계속 확인할 수 있게 한다

두 필드는 기존 행에 값이 없으면 null이며, 연장으로 실행 버전이나 발행 번호를 바꾸지 않는다
기존 instance_id, status, expires_at, hard_expires_at은 그대로 유지한다
DB migration은 없다

PostgreSQL 통합 검사에서 연장 응답의 snake_case 필드와 저장된 실행 버전 일치, 만료 시각 변경을 확인한다
운영 검증은 별도 QA 계정으로 생성·접속 후 같은 키의 동시 연장이 한 번만 반영되는지 확인한다
